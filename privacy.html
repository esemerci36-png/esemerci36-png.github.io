Forgotten Science

Privacy Policy

Effective 15 November 2026

Who we are

"Forgotten Science" is a private publishing tool operated by the owner of the Forgotten Science YouTube channel. It is used only to publish videos to that one channel. It is not offered to the public and has no other users.

What the tool accesses

With the channel owner's consent through Google OAuth, the tool uses these YouTube API Services scopes:

  • youtube.upload: to upload and schedule the channel's own videos.
  • youtube.readonly: to read the channel's own video list and metadata.
  • yt-analytics.readonly: to read aggregate performance numbers (views, watch time) for the channel's own videos, so we can learn which topics work.

The tool does not access any other user's account, and does not collect personal data about viewers. It never reads comments, subscriber identities or private messages.

How data is stored

The OAuth credentials are stored as encrypted secrets in a private GitHub repository and are used only by the automated job that uploads the channel's videos. Aggregate analytics numbers are kept only for the duration of that job. Nothing is sold, shared with or disclosed to third parties.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page. Stored credentials are deleted from the repository within 7 days of revocation or on request.

Contact

Questions about this policy can be sent through the contact details on the Forgotten Science YouTube channel's About page.
